## 一、核心内容

### 文章1：第七届 · 刘烈宏谈「可信数据空间的生命力」

**时间**：2024年4月29日下午，福州

**背景数据**：
- 2023年我国数据生产总量 **32.85ZB**，同比增长22.44%，占全球总量27.44%

**四个成效**：
1. **初步构建信任体系**：汽车行业数据空间共享数据资源超 **18PB**
2. **发挥乘数效应**：充电桩与电站数据互通 → 利用率提升 **20%**（直接利好朗新交能融合数据服务）
3. **生态协同初见成效**：63个试点单位形成 **7000个** 数据产品和服务，吸引2000+生态主体
4. **多源数据加快融合**：汇聚 **600+** 行业高质量数据集，支撑AI创新应用

**三个挑战**：
1. 应用仍需深化（重建设、轻应用）
2. 流通仍有堵点（标准协议、权责边界、收益机制不清晰）
3. 互联互通水平亟待提升（基础路径不兼容、信任机制不互认）

**四个坚持（未来方向）**：
1. 以应用为牵引 → 深入制造、低碳、医疗健康、金融、信用服务等高价值场景
2. 以价值为导向 → 持续扩大数据供给，探索「订单换数据」机制
3. 以产品为载体 → 推动创新发展，形成数据集、模型、应用解决方案等多层次产品体系
4. 以机制为重点 → 构建多方共赢生态，健全「531」工作体系

### 文章2：第九届 · 可信数据空间分论坛

**新增关键信息**：

**「十五五」规划**：将实施可信数据空间发展行动计划（国家战略层）

**首批试点城市**：
上海、宁波、温州、厦门、广州、**济南**（山东充电桩重镇）、雄安

**两本白皮书**（公众号后台回复「0429」获取）：
- 《城市可信数据空间实施路径报告》
- 《可信数据空间 跨域互信能力 评价规范》

**可信数据空间发展联盟（TDSA）**：
- 性质：国家数据局指导，中国信通院等50余家单位发起
- 规模：**826家**成员单位
- 核心任务：落实《可信数据空间发展行动计划（2024-2028年年）》，助力构建全国一体化数据市场

**出席重要人员**：邬贺铨院士、梅宏院士、周志华院士、中国信通院副院长敖立；南方电网、上海数据集团、中国汽研、钱塘征信、蚂蚁集团等

## 二、对朗新的战略价值

### 利好1：充电桩数据互通案例
> "通过充电桩与电站数据的互联互通，桩的利用率提升了20%"

→ **朗新核心论据**：充电桩运营+数据服务→利用率提升→REITs资产增值

### 利好2：国家「十五五」行动计划
→ **中交揭榜挂帅是大势所趋**：交通行业可信数据空间是「十五五」重点方向

### 利好3：7000+数据产品生态
→ **朗新数据服务变现空间大**：朗新的AI时序预测（充电站76%/电力90%/光伏95%）可作为数据产品接入

### 利好4：首批试点含济南
→ **山东是朗新重点布局区域**：充电桩运营+电力市场双重优势
