# Knowledge Graph - Skill 长期记忆

## 核心原则（已固化）

- **只学新增，不重复**：上传前检查索引是否已记录
- **知识精炼 > 字数**：提炼核心内容，不抄原文
- **标签规范化**：同一主题使用统一标签

## 知识库目录结构

| 目录 | 内容类型 |
|------|---------|
| 文档/ | Markdown、PDF、Word |
| 数据/ | CSV、JSON、Excel |
| 模板/ | 标准文档模板 |
| 报告/ | 分析报告、总结报告 |
| 其他/ | 不便分类的文件 |

## 知识点格式标准

```markdown
### [知识点标题]
- 摘要：[一句话核心内容，不重复标题]
- 标签：#标签1 #标签2
- 学习时间：YYYY-MM-DD
```

## 质量阈值（已固化）

| 指标 | 阈值 |
|------|------|
| 每文档知识点数 | ≥ 3 |
| 摘要字数 | ≤ 150字 |
| 标签数 | 1~3个 |

- knowledge-index.md（知识索引文件）
