# 碳达峰碳中和综合评价考核办法

## 文件信息

- **来源**：中共中央办公厅、国务院办公厅
- **发布日期**：2026年4月23日
- **原文来源**：中国能源新闻网 / 新华网
- **URL**：https://www.cpnn.com.cn/news/nytt/202604/t20260423_1883354.html

## 核心知识点

### 一、办法背景与目的

- 发挥碳达峰碳中和的战略牵引作用
- 构建碳排放总量和强度双控制度体系
- 推动地方党委和政府树立正确政绩观

### 二、适用范围

- 自2026年度起对各省（自治区、直辖市）党委和政府评价考核
- 评价内容：落实碳达峰碳中和目标任务、经济社会发展全面绿色转型进展

### 三、领导体制

- 中央组织部统筹指导
- 国家发展改革委会同有关部门实施
- 党政同责、一岗双责

### 四、评价考核指标体系

**控制指标**（5项）：
1. 碳排放总量
2. 碳排放强度降低
3. 煤炭消费总量
4. 石油消费总量
5. 非化石能源消费占比

**支撑指标**：节能、工业、城乡建设、交通运输、公共机构、碳排放权交易等领域

### 五、"十五五"时期目标（2026-2030）

- 2030年前碳达峰
- 2030年碳排放强度比2005年降低65%以上
- 2030年非化石能源消费占比达到25%
- 煤炭消费总量和石油消费总量达峰
- 合理控制煤电装机规模和发电量
- 力争年度新增清洁能源电量逐步覆盖全社会新增用电量

### 六、评价考核等次

| 等次 | 条件 |
|------|------|
| 优秀 | 控制指标和支撑指标全部达标 |
| 合格 | 不满足优秀/不合格条件 |
| 不合格 | ≥1项控制指标不达标 或 ≥3项支撑指标不达标 |

### 七、结果运用

- 约谈、通报提醒、通报表扬
- 作为领导班子和干部综合考核评价、选拔任用的重要参考
- 重大失职失责移交中央纪委国家监委、中央组织部追责

### 八、数据保障

- 主要依据国家统计数据
- 可采用全国碳市场数据和有关部门统计、调查、监测、核算数据
- 建立重要数据动态监测预警制度

### 九、后续计划

- 国务院国资委参照制定中央企业评价考核制度
- 各省应制定省级碳达峰行动方案

## 电力市场相关性分析

1. **煤电控制**：办法明确要求合理控制煤电装机规模和发电量，对煤电企业长期影响显著
2. **非化石能源**：2030年非化石能源消费占比25%目标将推动新能源发展
3. **碳市场**：支撑指标包含碳排放权交易，电力市场与碳市场协同机制加速
4. **新能源**：新增清洁能源电量覆盖全社会新增用电量目标为新能源消纳提供保障
5. **评价考核**：地方政府面临碳排放约束，可能影响电力项目审批和资源配置
