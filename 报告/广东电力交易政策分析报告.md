## 一、执行摘要（TL;DR）

广东是中国电力市场化改革的**第一梯队**，2024-2025 期间政策密集出台，形成了**"1 套基本规则 + 1 套实施方案 + N 项专项落地"** 的立体体系：

1. **市场骨架（2025）**：《广东电力市场交易基本规则（试行）》（2025-09-01）+《广东电力市场建设实施方案》（2025-01-01）——确立批发市场+零售市场双轨制，覆盖中长期、现货、辅助服务三类交易品种。
2. **虚拟电厂专项（2024-2025）**：省级实施方案 + 深圳/广州两地市落地措施 + 广州实施细则——广东是国内**最早把虚拟电厂做成独立市场主体**的省份之一，省级+市级两层政策叠加。
3. **核心特征**：**"放开两头、稳住中间"**——发电侧与售电侧充分市场化，输配电仍由电网企业按政府定价收取。
4. **对朗新启示**：
   - **市场化售电**业务：广东是核心战场（5 份完整制度文件已就位，市场成熟度全国领先）
   - **虚拟电厂 / 需求响应**：广东省级 + 深圳/广州两级政策红利期 2024-2026，是资源聚合商入场窗口
   - **数据产品**：广东电力市场数据（交易数据、负荷数据、虚拟电厂运行数据）是高价值数据空间产品素材

## 三、广东电力市场总体架构

### 3.1 两层市场结构（基本规则第三条）

广东电力市场交易分为**电力批发交易**和**电力零售交易**：

| 层级 | 主体 | 交易对象 | 价格形成 |
|------|------|---------|---------|
| **批发市场** | 发电企业、售电公司、电力大用户 | 双边协商、集中竞价、挂牌 | 市场化定价 |
| **零售市场** | 售电公司、终端用户 | 套餐式/定制化售电合同 | 市场化定价 |

> 引文：「第三条 电力市场交易分为电力批发交易和电力零售交易。」

**关键判断**：广东**始终保留"售电公司"作为批发与零售的中间层**，这是与江苏"售电公司淡出"模式的最大差异。朗新的市场化售电业务在广东**没有"被取消中间层"的风险**。

### 3.2 三类交易品种（基本规则 + 实施方案）

依据《实施方案》"三、市场交易类型"，广东覆盖三类交易：

1. **电力中长期交易**：多年、年度、月度、月内、多日等中长期合约（基本规则第十四条）
2. **电力现货交易**：日前、实时现货市场（实施方案明确 2025 年要"逐步开展"）
3. **辅助服务交易**：调频、调峰、备用、黑启动等（基本规则第七章）

**当前阶段判断**：
- ✅ **中长期交易**：已成熟运行（广东是首批 8 省现货试点之一）
- 🟡 **现货市场**：2025 年仍处"逐步开展"阶段，全国统一电力市场 2030 年目标，广东节奏符合
- ✅ **辅助服务**：广东电力辅助服务市场 2020 年已独立运行，规则成熟

### 3.3 市场主体分类

基本规则第二章确立的市场主体包括：

| 主体类型 | 准入条件 | 关键义务 |
|---------|---------|---------|
| 发电企业 | 符合产业政策、并网运行 | 参与交易、披露信息 |
| 售电公司 | 注册准入、履约保函 | 代理零售用户、报送合同 |
| 电力大用户 | 电压等级/用电量门槛 | 参与批发交易或选择售电公司 |
| 电网企业 | 输配电服务 | 输配电价、结算、调度 |
| 电力用户 | 零售合同关系 | 缴费、配合需求响应 |

**对朗新的关联**：
- **市场化售电**业务对应"售电公司"主体
- **新能源资产管理**业务对应"发电企业"主体（分布式光伏/分散式风电）
- **充电桩选址**需要的是用户侧数据（电力大用户/零售用户画像）
- **工商业储能**涉及"电源+负荷"双重身份认定——实施方案对储能的"双重身份"留了接口

## 四、价格机制详解

### 4.1 价格体系结构（基本规则第八章）

广东电力市场价格构成：

```
用户终端电价 = 上网电价 + 输配电价 + 政府性基金及附加 + 辅助服务费用 + 系统运行费用
```

其中：
- **上网电价**：发电企业参与市场形成（市场化）
- **输配电价**：政府定价（按"准许成本+合理收益"）
- **辅助服务费用**：按"谁受益、谁分摊"原则

### 4.2 价格上下限机制

基本规则设定了**价格上下限**作为风险防控：
- 中长期交易价格上下限（防恶意抬价/降价）
- 现货市场出清价格上下限（防极端波动）

### 4.3 结算机制

- **差价合约（CfD）**：中长期+现货衔接的金融结算工具
- **结算顺序**：发电侧按合约结算，零售侧按套餐结算
- **偏差处理**：实际用电量与合同电量的偏差按现货价格结算

**对朗新的关联**：
- **售电套餐定价**：必须考虑现货价格波动 + 辅助服务费用 + 输配电价三层叠加
- **偏差考核**：零售用户的负荷预测偏差直接影响售电公司利润——朗新的**负荷预测能力**是核心定价工具
- **数据产品的价值锚点**：用电数据 + 现货价格 + 合约数据交叉分析，是数据空间内"电力交易数据产品"的高价值素材

## 六、广东政策对朗新业务的关联分析

### 6.1 市场化售电业务

**匹配度**：🔴 极高

**政策依据**：
- 基本规则第三条"批发市场+零售市场"双轨制 = 售电公司持续存在
- 实施方案"鼓励售电公司创新服务" = 政策鼓励差异化

**朗新机会**：
- 广东售电市场规模全国前 3，市场成熟
- 政策允许"售电公司+增值服务"模式——朗新的负荷预测/能源管理服务可作为套餐增值
- 售电公司持续准入 = 朗新"市场化售电"产品不需要担心制度性退出

### 6.2 新能源资产管理业务

**匹配度**：🟡 中等

**政策依据**：
- 基本规则：发电企业可作为市场主体参与批发交易
- 实施方案：对分布式能源的接入和消纳有"鼓励并网+就近交易"导向

**朗新机会**：
- 分布式光伏/分散式风电可作为发电主体参与中长期交易
- 绿电交易/绿证机制（实施方案明确支持）
- ⚠️ 风险：储能的"双重身份"（电源+负荷）认定可能影响业务边界

### 6.3 充电桩选址业务

**匹配度**：🟡 中等

**政策依据**：
- 基本规则对零售用户/电力大用户的数据要求
- 实施方案对"电力用户画像"的数据需求（支撑需求响应）

**朗新机会**：
- 充电桩选址需要**电力负荷数据 + 用户出行数据**交叉——是数据空间产品的典型场景
- 政策要求售电公司报送合同数据 = 朗新可以反向获取零售用户画像
- ⚠️ 注意：充电桩本身不属于电力市场主体，但其用户是

### 6.4 工商业储能业务

**匹配度**：🟢 高

**政策依据**：
- 基本规则对储能的"电源属性+负荷属性"双重身份
- 实施方案对"电源侧储能、电网侧储能、用户侧储能"的分层定位
- 虚拟电厂政策：储能是虚拟电厂的核心聚合资源

**朗新机会**：
- 储能+虚拟电厂组合：储能作为聚合资源接入虚拟电厂，可获得**容量补偿 + 调用补偿 + 现货市场套利**三重收益
- 广东工商业储能政策窗口期 2024-2026
- 数据空间价值：储能运行数据 + 电力市场数据 = 高价值时序数据产品

## 九、风险与不确定性

- **基本规则（试行）** 意味着 2025-09 之后还会有正式版，条款可能微调

- **政策更新**：报告基于截至 2026-09-24 的洛书版本，后续政策出台需更新

### 9.3 业务风险

- **售电公司中间层**是否长期保留：广东目前保留，但参考其他省份经验，未来 5-10 年有"再市场化"压力

- **虚拟电厂准入门槛**：影响聚合商资质申请的难度评估

## 十、附录：广东电力市场核心术语

| 术语 | 定义 |
|------|------|
| 中长期交易 | 月度以上的电力合约交易 |
| 现货交易 | 日前/实时市场，节点电价或区域电价 |
| 辅助服务 | 调频、调峰、备用、黑启动等电网稳定性服务 |
| 售电公司 | 在批发市场购电、向零售用户售电的中间商 |
| 电力大用户 | 直接进入批发市场的大型用电企业 |
| 偏差考核 | 实际用电量与合同电量的差额结算 |
| 虚拟电厂 | 通过聚合分布式资源（储能、可调负荷）参与电网调度的实体 |
| 容量补偿 | 对发电/储能资源的容量可用性给予的固定补贴 |
| 调用补偿 | 对发电/储能资源实际调用时给予的补贴 |
